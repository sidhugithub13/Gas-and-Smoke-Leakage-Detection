# Gas-and-Smoke-Leakage-Detection

The objective is to identify the leakage of gas/smoke in the environment using smoke sensor.


**MQ- 6 Smoke Sensor:**

![image](https://github.com/user-attachments/assets/52b76c11-0560-4c95-9037-c6ce9fb33607)                                      



![image](https://github.com/user-attachments/assets/a9b18116-96dd-430a-b542-b43f4a3dbe3e)



The smoke sensor is the MQ-6. This is a sensor that is not only sensitive to smoke, but also to flammable gas.
The MQ-6 smoke sensor reports smoke by the voltage level that it outputs. The more smoke there is, the greater the voltage that it outputs. 
Conversely, the less smoke that it is exposed to, the less voltage it outputs.

The MQ-6 also has a built-in potentiometer to adjust the sensitivity to smoke. By adjusting the potentiometer, it is possible to change how sensitive it is to smoke, 
so it is a form of calibrating it to adjust how much voltage it will put out in relation to the smoke it is exposed to.

**Hardware Requirements:**

•	1x MQ-6 Smoke Sensor
•	1x Arduino board
•	1x Buzzer
